# Public Assets

This directory is reserved for small, public documentation and promotional
assets such as optimized screenshots or product diagrams.

Only assets that are safe to publish should be added here. Do not commit
customer JARs, private artwork, source material, secrets, or large unoptimized
media files. Prefer PNG or WebP for screenshots; use GIF only when motion is
necessary to explain a feature.

When an asset is added, reference it from the page where it provides useful
context and keep its filename descriptive.
