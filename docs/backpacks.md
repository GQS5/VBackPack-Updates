# Backpacks

VBackpack backpacks are portable, persistent storage objects designed to grow
with a player. They are more than extra inventory slots.

## Backpack Philosophy

- Contents persist with the individual backpack.
- Backpacks have identity and state; they are not interchangeable command
  inventories.
- Multiple backpack types support a progression journey.
- A backpack can become the foundation for Artifact and Achievement progression.

The exact tier names, capacities, recipes, prices, and acquisition rules may
vary with the current release or server configuration. Use the current in-game
interface and configuration for those values rather than relying on guessed
defaults in a general guide.

For storage behavior and backup guidance, see [Storage](storage.md). For the
systems layered onto a backpack, continue to [Artifacts](artifacts.md).
