# Configuration

VBackpack is configured through the plugin's generated configuration files.
Exact options can vary by release, so use the comments and defaults generated
by the installed version as the authoritative reference.

Configuration files belong under the plugin data directory. Do not publish
credentials, private paths, or server-specific configuration in support posts.

## Safe Practices

- Back up the server before changing storage or progression settings.
- Change one related setting at a time and restart when the installed release
  requires it.
- Review startup warnings after editing YAML.
- Treat the current in-game interfaces as authoritative for tier, Artifact,
  Fusion, and Achievement behavior.

Detailed option coverage will expand as release-specific public configuration
documentation becomes available. For persistence and backend guidance, see
[Storage](storage.md).
