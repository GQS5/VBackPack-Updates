# Fusion

Fusion is VBackpack's Artifact progression system. It gives players a path to
advance their Artifact collection through the in-game interface instead of
treating Artifacts as static bonuses.

The available inputs, costs, progression limits, and outcomes are intentionally
not duplicated here because they are release and configuration dependent. Open
the current Fusion interface in-game for the authoritative rules before
committing items.

For the concepts and confirmed lineup, see [Artifacts](artifacts.md). For
administrative visibility into Artifact state, see [Admin Inspector](admin-inspector.md).
