# FAQ

## Does VBackpack require another plugin?

No external plugin dependency is required. The SQLite JDBC library is loaded
automatically by Paper.

## Does VBackpack require MySQL?

No. VBackpack uses SQLite-backed persistence and does not require a MySQL
server.

## Does it support Folia?

Yes. Folia 1.21.11 is a documented compatibility target.

## Does it require Java 21?

Yes. Java 21 is required.

## Are admin inspections read-only?

Yes. The Admin Inspector is designed to inspect storage and progression without
modifying a player's backpack.

## Does it support offline player inspection?

Yes. The Player Selector supports online and offline players.

## Where do I download updates?

Customer downloads are distributed through the official marketplace resource,
not this repository.

## Where is the source code?

VBackpack source code is not hosted in this public documentation repository.

## How are plugin updates announced?

The update checker reads the public [stable metadata](https://github.com/GQS5/VBackPack-Updates/blob/main/stable.json). Release
announcements and customer downloads are handled through the official
marketplace resource.
