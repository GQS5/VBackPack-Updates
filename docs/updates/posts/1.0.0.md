# VBackpack 1.0.0

**Initial Stable Release** · August 26, 2026

VBackpack 1.0.0 is the first stable milestone for the public update-checking
system. It gives server owners clear update notifications without taking
control of downloading or installing server software.

## What's New

### A safer update path

- Reads a public, credential-free VBackpack update manifest.
- Supports `/backpack update`, with `/vbp update` and `/bp update` aliases.
- Provides configurable console and permitted-operator notifications.
- Includes periodic asynchronous checks with bounded retry, backoff, and rate-limit handling.

### Reliability by default

Requests are non-blocking and coalesced when multiple checks overlap. Results
are delivered through Paper/Folia-safe paths, while reload and shutdown
handling prevents stale scheduled work and repeated failure notifications.

### Server-owner control

The update checker checks and notifies only. It does not download or install
releases, use a GitHub token, collect telemetry, or transmit player or server
identity data.

### Compatibility

The release history verifies Java 21 and tested Paper/Folia 1.21.11 paths.
SQLite remains the default storage backend and is loaded through Paper's
declared library loader.

1.0.0 is a milestone for the update system, not a claim that every VBackpack
feature first appeared in this version. Earlier verified feature history is
available in the [full Changelog](../changelog.md).
